# Example Outputs

The `examples/` directory contains synthetic example outputs that reproduce the structure and key fields generated by the variant prioritization tools evaluated in this workflow.

These files are provided to facilitate workflow understanding, testing, and reproducibility without requiring access to clinical datasets.

## Included Example Files

| File | Description |
|------|------|
| `exomiser_output_example.tsv` | Example candidate ranking generated by Exomiser |
| `lirical_output_example.tsv` | Example phenotype-driven prioritization output generated by LIRICAL |
| `amelie_output_example.tsv` | Example literature-based prioritization output generated by AMELIE |

## Intended Uses

The example files can be used to:

- Understand the output structure produced by each prioritization tool
- Test integration and filtering scripts included in the workflow
- Validate parsing and downstream analysis procedures
- Reproduce workflow execution using non-clinical data
- Serve as templates for adapting the workflow to additional tools or datasets

## Data Privacy

No real patient data are included in this repository.

The example outputs were generated exclusively for demonstration purposes and contain synthetic data designed to mimic the structure of real tool outputs while preserving patient confidentiality.

This approach allows the workflow to be shared, reproduced, and extended without exposing sensitive clinical information.
